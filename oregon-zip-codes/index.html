Oregon ZIP Codes

All 479 Oregon ZIP codes, searchable by ZIP code, city or county.

Home › Oregon ZIP Codes

Oregon has 479 active ZIP codes, and every one of them begins with 97. 392 are standard delivery ZIP codes, and the rest are PO box or single-organization ZIP codes. The 970–973 prefixes cover Portland, the north coast and the northern Willamette Valley; 974 covers Eugene and the southern valley; 975 covers southern Oregon; 976 covers Klamath and Lake counties; 977 covers Central Oregon; and 978–979 cover Eastern Oregon. Frequently Asked Questions

How many ZIP codes are in Oregon?

Oregon has 479 active ZIP codes: 392 standard delivery ZIP codes plus PO box and single-organization ZIP codes.

What do Oregon ZIP codes start with?

Every Oregon ZIP code starts with 97, running from 97001 (Antelope) to 97920 (Westfall).

What is the ZIP code for Portland, Oregon?

Portland has many ZIP codes, including 97086, 97201, 97202, 97203, 97204, 97205, 97206, 97209. Downtown Portland is 97204 and 97205.

What is the ZIP code for Salem, Oregon?

Salem ZIP codes include 97301, 97302, 97303, 97304, 97305, 97306, 97317.

What is the ZIP code for Eugene, Oregon?

Eugene ZIP codes include 97401, 97402, 97403, 97404, 97405, 97408, 97412, 97455.

Does a ZIP code tell me which city I live in?

Not always. ZIP codes are drawn for mail delivery, so many homes outside city limits use a nearby city’s name and ZIP code. Check your county’s property records to confirm which city, if any, you are in.
